# LÜQ — A Quiet Presence

> *An emotion-aware character that responds not with words, but with presence.*

LÜQ is an exploratory prototype designed to interpret emotional sentiment from text input and react visually through atmospheric shifts, organic shape morphing, and brief, poetic "whispers". 

## 🧠 Core Philosophy
Built on the principle of **"feeling over features"**, LÜQ is not a standard chatbot. It does not argue, converse, or offer solutions. It simply reads the emotional tone of the user's input and attempts to make them feel understood.

## ✨ Features
* **Emotion Engine:** Keyword-based sentiment analysis detecting 7 core emotions (Joy, Sadness, Calm, Anxiety, Anger, Tired, Love).
* **Organic Morphing:** The character's SVG/CSS body organically continuously morphs, simulating breathing.
* **Ambient Reactions:** Background particle density, speed, and color shift dynamically based on detected mood.
* **Micro-Expressions:** Subtle shifts in eye shape and a minimal mouth element convey silent empathy.
* **Intensity Scaling:** Recognizes intensifiers (e.g., "very", "super") to deepen visual reactions.

## 🛠️ Tech Stack
This prototype was intentionally built from scratch without heavy frameworks to ensure the codebase remains as intentional and minimal as the design.
* **HTML5** — Semantic structure
* **CSS3** — Complex keyframe animations, CSS variables for mood themes
* **Vanilla ES6 JavaScript** — Modular architecture handling state and canvas rendering

## 🚀 Running Locally
Simply open `index.html` in your browser, or run a local static server:
```bash
npx serve .
```
